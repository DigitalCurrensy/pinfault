# PINFAULT whitepaper

## The job

A pin on a lunar or Mars map looks official. DEMs have voids. Frames disagree. A crater rim is tens to hundreds of metres from the labeled point. Every lighting tool downstream inherits the lie.

PINFAULT scores a coordinate against DEM completeness, slope, named-feature offset, and frame mismatch. It does not pretty-print the pin.

## Void fraction

`void_fraction = n_invalid / n_cells`. Invalid is nodata, fill, NaN, or out-of-range elevation. A fill value is a hole, not zero slope. Gate is strict greater-than 0.15. DEM unfetched this wave.

## The memo

The paper on the pin is a PIN MEMO. Never CERTIFICATE. Never survey-grade. Offset and voids still issue. Undeclared identity does not. Do-not-traverse is an abort, not a traverse plan. Counsel unsigned.

Apollo 12 LM is a different pin. One coordinate remains PIN-A11-LM. Surveyor 3 is not West crater.
